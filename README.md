# C Programming Practice

A collection of C exercises covering introductory programming, arrays, functions, recursion, and pattern printing.

## Repository layout

- `C_Programming/IntroToC/` — introductory exercises
- `C_Programming/Arrays/` — array exercises
- `C_Programming/Function/` — function exercises
- `C_Programming/Recursion/` — recursion exercises
- `C_Practice/` — additional numbered practice problems

## Compile and run

With GCC installed, compile an individual source file from the repository root:

```sh
gcc C_Programming/IntroToC/factorial.c -o factorial
./factorial
```

On Windows, run `factorial.exe` after compiling. Each source file is a separate exercise and may have its own input prompts.

This repository is a learning collection. For a quick starting point, try the factorial example above, then browse the folders by topic.
