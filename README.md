# C Programming Practice

A structured collection of C exercises covering programming fundamentals, arrays, functions, recursion, and problem solving.

## Repository structure

- `C_Programming/IntroToC/` — introductory exercises
- `C_Programming/Arrays/` — array problems
- `C_Programming/Function/` — function-based programs
- `C_Programming/Recursion/` — recursive solutions
- `C_Practice/` — additional numbered exercises

## Requirements

Install GCC or another C compiler and run commands from the repository root.

## Compile and run an example

Compile the factorial program:

```sh
gcc C_Programming/IntroToC/factorial.c -o factorial
```

Run it on macOS or Linux:

```sh
./factorial
```

On Windows, run:

```powershell
.\factorial.exe
```

Each source file is an independent exercise and may prompt for input. Browse the folders by topic to find more examples.
